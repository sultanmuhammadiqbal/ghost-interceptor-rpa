# GHOST // INTERCEPTOR [SYS.02]
**Autonomous Vision-Guided Web Operator (Set-of-Mark RPA Engine)**

Aplikasi Web Teleoperation & Mystery Shopper RPA dengan estetika **Zirka Interceptor (Tactical Defense-Tech / Swiss Industrial Minimalism)**.

---

## 1. Strict Design System: "Zirka Interceptor" Aesthetic
- **Zero-Radius Tactical Geometry**: Seluruh elemen menggunakan sudut tajam (`rounded-none` / `0px`), garis grid terekspos `1px solid #222222`, dan penanda sudut mikro (`+`).
- **Strict 4-Color Palette**:
  - `#0A0A0A` — Matte Carbon / Obsidian (Background Utama)
  - `#111111` — Deep Graphite (Surface / Panel)
  - `#F4F4F0` & `#737373` — Crisp Bone White & Muted Technical Grey (Tipografi)
  - `#FF4500` — International Signal Orange (Aksen tunggal untuk kursor Bezier, tag Set-of-Mark aktif, dan tombol eksekusi utama)

---

## 2. Set-of-Mark (SoM) DOM Grounding (`[#01]` s/d `[#09]`)
- `[#01]` — Pop-up / Promo Interstitial Close Button
- `[#02]` s/d `[#06]` — Tombol Varian Ukuran / Spesifikasi (mis. `EU 40` s/d `EU 44`, `SZ XS` s/d `SZ XL`)
- `[#07]` — Dynamic Price Display Container
- `[#08]` — Inventory / Stock Status Telemetry Node
- `[#09]` — Primary Purchase CTA (`+ KERANJANG` / `BELI SEKARANG`)

---

## 3. Hard-Guard Voice Over & Single-Product Isolation
- **Single-Product Focus**: Hanya mengaudit 1 produk target secara spesifik tanpa perbandingan lintas produk.
- **Deterministic Voice-Over Hard-Guard**: Wajib mematuhi `words <= 22` dan `chars <= 145` baik di API TypeScript (`src/lib/ghost-engine.ts`) maupun modul Python (`scripts/ghost_operator.py`).
